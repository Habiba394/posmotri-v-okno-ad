# Посмотри в окно

Проектная работа Яндекс Практикума: стилизация и доработка готового приложения, которое показывает видео из окон разных городов. Приложение включает список карточек с видео и форму поиска по городу и времени суток.

Репозиторий проекта: https://github.com/Habiba394/posmotri-v-okno-ad

## 📂 Структура проекта

- `index.html` — основная разметка страницы и шаблоны (`<template>`) для карточки, прелоадера, кнопки «Показать ещё» и блока ошибки.
- `styles/style.css` — стили проекта: лейаут на Flexbox, карточки, форма, кнопки и их интерактивные состояния.
- `styles/preloader.css` — стилизация прелоадера.
- `styles/error.css` — стилизация блока с ошибкой.
- `scripts/script.js` — логика приложения: загрузка видео из API, переключение роликов, поиск и пагинация карточек.
- `fonts/` — шрифты Oswald и Fira Sans Condensed, а также файл их подключения `fonts.css`.

## ✅ Что сделано

- Реализован адаптивный лейаут страницы на Flexbox в соответствии с макетом.
- Созданы кастомные чекбоксы с использованием псевдоэлемента `::after` и псевдокласса `:checked`.
- Добавлены интерактивные состояния `:hover`, `:active` и `:focus-visible` для кнопок, карточек и полей формы (доступность и UX).
- Настроена элегантная обрезка длинного текста: многоточие для заголовков и `line-clamp` для описаний карточек.
- Реализовано абсолютное позиционирование прелоадеров внутри блоков с видео и списком карточек.

## 🚀 Запуск

1. Клонируйте репозиторий или скачайте архив с проектом.
2. Откройте файл `index.html` в браузере. 
   *(Рекомендуется использовать расширение **Live Server** в VS Code для корректной работы).*
3. Видео и данные будут автоматически подгружаться из API Яндекс Практикума.
